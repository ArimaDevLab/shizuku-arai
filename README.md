# しずくのおうち時間

洗い物をしている間だけ進む、ブラウザゲームです。

- マイクで「水が流れる音」を検知すると、しずくがおうちとお庭を少しずつ整えていきます
- 食器を洗う「カチャ」という音があると早く進み、水を流しているだけだとゆっくり進みます
- 水を止めて洗っている間は「節水のしずく」がたまり、節水できた時間として記録されます
- 洗い物が終わると「おつかれさま」カードが出て、今日の記録を画像で保存・共有できます
- 場所：くもった窓辺 → しおれたハーブ → お庭の花だん → バラのアーチ
- マイクが使えない場合は、手動ボタンまたは画面タップでオン・オフできます
- 音は端末内で判定するだけで、録音や送信はしません

## ホーム画面に追加（PWA）

スマホのChromeで開き、「ホーム画面に追加」（または画面下の「ホーム画面に追加する」ボタン）でアプリのように使えます。
洗い物中は画面が消えないようにしています（対応ブラウザのみ）。

## ファイル

- `index.html` … ゲーム本体
- `manifest.webmanifest` … ホーム画面に追加するための設定
- `sw.js` … オフラインでも開けるようにするキャッシュ
- `icons/` … アプリのアイコン
